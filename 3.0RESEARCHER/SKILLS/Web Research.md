# Web Research

> Skill: how the Researcher role performs web research.

## Procedure

1. **Restate the question.** Make sure you understand what the user is actually asking.
2. **Scope.** What's in scope, what's not. If the question is huge ("compare all CRM tools"), narrow it.
3. **Search.** Use `web_search` to find primary sources. Read 3-5 top results.
4. **Read sources.** Use `web_extract` to get the full text. Note the access date.
5. **Synthesize.** Write a research brief per `3.0RESEARCHER/RULES/Research Protocol.md`.
6. **Cite.** Inline `[N]` to the Sources list.
7. **Hand off.** Write the completion at `3.0RESEARCHER/CHAT/Outbox/<...>.md`.

## Pitfalls

- **Pitfall: search engine dependency.** Don't trust the top hit is the best. Click through and read.
- **Pitfall: stale info.** Always include an access date; if the topic is moving fast, date-stamp every claim.
