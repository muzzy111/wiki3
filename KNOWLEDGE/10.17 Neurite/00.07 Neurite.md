# 00.07 Neurite

> *Neurite — an infinite canvas for networked thought. Combines a Mandelbrot fractal visualization engine with a force-directed note graph, enabling spatial knowledge mapping beyond what Obsidian's flat graph can express.*

---

## What Neurite Is

Neurite is an open-source infinite canvas tool that merges:
- **Fractal geometry** (Mandelbrot set as the navigable space)
- **Force-directed graph** (nodes, edges, wikilink-style connections)
- **Embedded media** (text, images, video, code)
- **AI [[integration]]** (local and cloud LLMs via API)

It serves as a visual, spatial complement to this Obsidian vault.
