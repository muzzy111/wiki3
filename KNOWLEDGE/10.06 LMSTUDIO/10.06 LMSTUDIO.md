# 10.06 LMSTUDIO

> *LM Studio — the premier local LLM runtime for running open-weight models on consumer hardware. Full OpenAI-compatible API, MCP server support, and model management.*

---

## What LM Studio Is

LM Studio is a desktop application and local server for running large language models privately:
- **Local inference** — GPU/CPU hybrid, supports GGUF format
- **OpenAI-compatible API** — drop-in replacement for cloud APIs
- **Anthropic-compatible API** — Claude-style API support
- **MCP Server** — native MCP protocol support
- **Model management** — download, version, and share models
- **Chat UI** — built-in conversation interface
