`Advanced`

You can set default load settings for each model in LM Studio.

When the model is loaded anywhere in the app (including through [`lms load`](https://lmstudio.ai/docs/cli#load-a-model-with-options)) these settings will be used.

---

### Setting default parameters for a model

Head to the My Models tab and click on the gear  icon to edit the model's default parameters.

![](https://lmstudio.ai/assets/marketing/docs/model-settings-gear.webp)

This will open a dialog where you can set the default parameters for the model.

<video controls=""><source src="https://files.lmstudio.ai/default-params.mp4" type="video/mp4"><p>Your browser does not support the video tag.</p></video>

Next time you load the model, these settings will be used.

Pro Tip

## Advanced Topics

### Changing load settings before loading a model

When you load a model, you can optionally change the default load settings.

![](https://lmstudio.ai/assets/marketing/docs/load-model.png)

### Saving your changes as the default settings for a model

If you make changes to load settings when you load a model, you can save them as the default settings for that model.

![](https://lmstudio.ai/assets/marketing/docs/save-load-changes.png)
