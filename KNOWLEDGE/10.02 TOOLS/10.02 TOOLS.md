# 10.02 TOOLS

> *The tool ecosystem powering [[agents]] in this system — MCP servers, APIs, CLIs, and integrations that extend what [[agents]] can do beyond their base capabilities.*

---

## What "Tools" Means Here

In the context of AI [[agents]], **tools** are functions, APIs, or services that an agent can invoke to interact with the world:
- **MCP servers** — Model Context Protocol servers that expose capabilities to [[agents]]
- **CLI tools** — Command-line tools invoked via terminal
- **APIs** — External service APIs [[agents]] can call
- **Browser tools** — Webpage reading, screenshot, interaction
- **File system tools** — Read, write, search files
- **Code execution** — Python, PowerShell, Bash runtimes
