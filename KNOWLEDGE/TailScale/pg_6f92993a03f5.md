# Control AI access

Last validated Jun 9, 2026

\[Missing snippet: aperture\_release\_note.mdx]

Aperture uses [Tailscale's identity layer][kb-tailscale-identity] to automatically authenticate users. Control which users can reach the Aperture instance through tailnet access control rules, then use [Aperture grants][kb-aperture-grants] to define which models each user or group can access. To reference Tailscale groups in grants, enable [visible groups][kb-visible-groups]. Aperture is deny-by-default: without grants, users can connect but cannot access any models.

Grants also govern access to MCP tools, resources, and connectors. Aperture uses a three-layer authorization model -- configuration defines what is available, grants control who can access it, and credentials handle upstream authentication -- that applies uniformly to models and connectors. For details on granting MCP and connector access, refer to [grant access to MCP tools][kb-grant-mcp-tool-access] and [connectors][kb-aperture-connectors].

For background on how identity works, refer to [how Aperture works][kb-how-aperture-works]. To understand the grants model itself, including deny-by-default access and precedence, refer to [how Aperture grants work][kb-how-grants-work].
