# Troubleshooting guide

Last validated Jan 5, 2026

This topic contains various suggestions and tips to help troubleshoot common issues. If you have additional issues, [contact Tailscale Support][co-contact-support].

## Connectivity and network issues

* For basic device connectivity issues, refer to [Troubleshoot device connectivity][kb-troubleshoot-connectivity].
* For network configuration issues, refer to [Troubleshoot network configuration][kb-troubleshoot-network-configuration].
* For general network troubleshooting (that is, not specific to Tailscale), refer to [Basic network troubleshooting][kb-basic-network-troubleshooting].

## Issues related to a specific operating system

For OS-specific Tailscale troubleshooting, refer to the following:

* [Troubleshooting guide for Apple][kb-troubleshooting-apple]
* [Troubleshooting guide for Linux][kb-troubleshooting-linux]
* [Troubleshooting guide for Windows][kb-troubleshooting-windows]

## Mobile device issues

For mobile device issues, refer to [Troubleshooting mobile devices][kb-troublehsooting-mobile].

## Container issues

For container issues, refer to [Troubleshooting containers][kb-troubleshooting-containers].

## Cloud environment issues

For cloud environment issues, refer to [Troubleshooting cloud environments][kb-troubleshooting-cloud].

## Additional resources

If you need to generate a bug report to help Tailscale Support debug an issue, follow the instructions at [Generate a bug report][kb-bug-report].

If you want to enable debug mode for the Tailscale client menu to assist in troubleshooting, follow the instructions at [Debug menu and options][kb-debug-menu].
