Aperture by Tailscale is a centralized AI gateway that secures, monitors, and routes LLM requests across your organization. Aperture uses [Tailscale's identity layer][kb-tailscale-identity] to automatically authenticate users, eliminating the need to distribute API keys. It routes requests to upstream LLM providers such as OpenAI, Anthropic, and Google without requiring changes to existing tools or workflows.
