# [[Sort-Tag-Audit]] Guide

The Sort & Tag Audit [[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[template]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]] generates a dated audit note that surfaces vault health problems: unprocessed notes sitting in the Inbox, notes missing required tags, and notes filed in the wrong folder for their domain. It is designed to be both a human-readable [[review]] [[dashboard]] and a machine-readable task queue that Antigravity can read and act on automatically.

1. **Frontmatter Metadata** (all set automatically — no [[[[prompts]]]]):
   - `title`: Set to `"Sort & Tag Audit — YYYY-MM-DD"` using today's date.
   - `type`: Set to `audit`.
   - `created`: Today's date.
   - `tags`: Pre-tagged with `system/audit`, `system/sort`, `domain/obsidian`.
   - `antigravity-task`: Set to `pending` — signals Antigravity that this note is an active task queue.
   - The file is **automatically renamed** to `sort-audit-YYYY-MM-DD` at creation time.

2. **Core Sections**:
   - **Antigravity Instructions Callout**: A `[!tip]` block at the top that tells Antigravity exactly how to process each item in the queues below — the five-step protocol for inferring domain, applying tags, moving files, updating [[status]], and checking off items.
   - **Inbox — Unprocessed**: A live Dataview table showing every note in the `Inbox/` folder with `[[status]]: unprocessed` or `[[status]]: unread`, sorted oldest-first to process the backlog in order.
   - **Missing Required Tags**: A live Dataview table showing up to 20 vault-wide notes that are missing a `domain/` tag — the most common tagging gap.
   - **Misrouted Files**: A live Dataview table comparing each note's `domain` frontmatter field to its actual folder path, flagging notes that are filed in the wrong place.
   - **Processed Today**: A live Dataview table showing all notes that were marked `processed` on today's date — a confirmation log of what was handled.
   - **Vault Health Snapshot**: Two summary Dataview queries — one showing the total count of unprocessed/unread notes, and one showing a breakdown of how many notes exist per domain.
   - **Antigravity Batch Tasks**: A plaintext code block containing a structured batch instruction set that you can copy into an Antigravity chat session to automate the entire sort-and-tag run.

## Running an Audit: Human Workflow

Work through each section top to bottom:

2. **Missing Required Tags**: Open each flagged note and add the missing `domain/`, `type/`, `source/`, and `[[status]]/` tags per the [[Tag-Taxonomy]].
3. **Misrouted Files**: Move files from their current folder to the correct `Muzzy/Processed/{domain}/` path.
4. **Check the Processed Today table** to confirm your work is showing up.
5. **[[Review]] the Vault Health Snapshot** to see if the unprocessed count is trending down.

## Running an Audit: Antigravity Batch Mode

To let Antigravity handle the audit automatically:

1. Generate the audit note using either Option 1 or Option 2 above.
2. Copy the entire **Antigravity Batch Tasks** code block from the bottom of the audit note.
3. Paste it into a new Antigravity session (or tell Antigravity: "Run the sort audit for today — the audit note is `sort-audit-YYYY-MM-DD`").
4. Antigravity will read the audit note, process each item in the Inbox queue, apply tags per the [[Tag-Taxonomy]], [[update]] statuses, and move files to the correct folders.
5. Check the **Processed Today** Dataview table in the audit note to verify what was handled.

## Cadence

Run a Sort & Tag Audit:
- **Daily** if you clip or ingest content regularly.
- **Weekly** as a minimum vault hygiene check.
- **Ad hoc** after any large batch of imports or after Antigravity has run an automated ingestion session.
