# [[PDF-Research-Ingest]] Guide

The PDF Research Ingest [[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[template]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]] is designed to capture, structure, and track academic papers, technical reports, and any PDF-based documents as they enter the vault. ## Structure and Function of the [[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[Template]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]

1. **Frontmatter Metadata** (all fields collected via interactive [[[[prompts]]]]):
   - `title`: The paper or document title, entered manually.
   - `authors`: One or more author names, comma-separated.
   - `year`: [[[[Publication]]]] year, or left blank to default to `unknown`.
   - `source`: The originating URL, DOI, or local file path.
   - `domain`: Selected from a dropdown — `AI / ML`, `OSINT`, `Security`, `Finance`, `PKM / Tools`, or `Other`.
   - `doc-type`: Selected from a dropdown — `Research paper`, `Technical [[[[report]]]]`, `Article`, `Book chapter`, `Documentation`, or `Other`.
   - `[[status]]`: Automatically set to `unprocessed` — the starting point in the processing pipeline.
   - `priority`: Defaults to `normal`; edit manually to `high` or `low` after ingestion.
   - `processed`: Left blank (`~`) until the note is fully worked through.
   - `antigravity-task`: Left blank (`~`) until Antigravity is assigned an action on this note.
   - The file is **automatically renamed** to `YYYY-MM-DD-title-slug` at creation time.

2. **Core Sections**:
   - **Source Metadata Callout**: An `[!info]` block at the top displaying authors, year, domain, and source URL at a glance — no need to open frontmatter.
   - **Abstract / Summary**: Paste the paper's abstract here, or write a 3–5 sentence summary after reading. An `ANTIGRAVITY-HINT` comment signals Antigravity to fill this automatically if you leave it blank and run a task.
   - **Key Concepts**: A bullet list for the 3–7 most important ideas, terms, or contributions extracted from the document.
   - **Claims & Evidence**: A table to log specific factual claims, supporting quotes or data, and your confidence level (`high`, `med`, or `low`).
   - **Connections**: A live Dataview query that surfaces other vault notes sharing the same `domain/` tag — automatic discovery of related material.
   - **My Notes & Critique**: A personal commentary block for disagreements, questions, and follow-up thoughts.
   - **Action Items**: A task checklist for any follow-up work triggered by the document.
   - **Tagging Checklist**: A processing checklist — when all boxes are checked, the note is ready for its [[status]] to be updated to `processed`.
   - **SORT-TARGET comment**: A hidden HTML comment written at the bottom of the note that tells Antigravity (and the Sort & Tag Audit) where this file belongs once processed.

### Option 1: Interactive Insertion via QuickAdd (Recommended)

1. Drop the PDF into your vault's `Inbox/` folder (or note the file path / URL).
2. Open the Command Palette (`Ctrl+P`) and run **QuickAdd: Run "PDF Research Ingest"** (or whatever name you gave the macro).
3. Answer the [[[[prompts]]]] in sequence:
   - **Paper / doc title**: Type the document's title.
   - **Author(s)**: Type one name or a comma-separated list. Type `unknown` if authorship is unclear.
   - **Year**: Type the four-digit year, or press Enter to leave blank.
   - **Source URL or file path**: Paste the DOI, URL, or local path to the PDF.
   - **Domain selector**: Pick the closest domain from the dropdown.
   - **Doc-type selector**: Pick the document type from the dropdown.
4. ## Processing Workflow

After ingestion, work through the note in this order:

1. **Fill the Abstract** — paste or write a summary.
2. **Extract Key Concepts** — pull the 3–7 most important ideas.
3. **Log Claims** — add the strongest or most surprising claims to the evidence table.
4. **[[Review]] Connections** — check the Dataview query for related notes; add `[[wikilinks]]` where relevant.
5. **Write your critique** — what do you agree with? What's missing?
6. **Complete the Tagging Checklist** — tick all boxes.
7. **[[Update]] [[status]]** — change `[[status]]: unprocessed` → `[[status]]: processed` in frontmatter.
8. The `SORT-TARGET` comment at the bottom tells Antigravity (or you) which folder to move the file to.
