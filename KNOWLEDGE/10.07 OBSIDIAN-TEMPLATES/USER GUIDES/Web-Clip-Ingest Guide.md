# [[Web-Clip-Ingest]] Guide

The Web Clip Ingest [[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[template]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]] is designed for saving and processing content captured from the web — articles, tutorials, tools, Reddit threads, news, and reference docs. It works best alongside the **MarkDownload** browser extension, which converts any web page to Markdown and saves it directly to your vault's `Inbox/` folder. It uses Templater and QuickAdd to tag, classify, and scaffold a reading and processing workflow.

## Structure and Function of the [[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[Template]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]

1. **Frontmatter Metadata** (collected via interactive [[[[prompts]]]]):
   - `title`: The page title, entered manually or auto-derived from the URL if left blank.
   - `url`: The source URL, entered manually.
   - `clipped`: Automatically set to today's date (`YYYY-MM-DD`).
   - `domain`: Selected from a dropdown — `AI / ML`, `OSINT`, `Security`, `Finance`, `PKM / Tools`, `Dev / Code`, or `Other`.
   - `clip-type`: Selected from a dropdown — `Article`, `Tutorial`, `Thread`, `Tool / product`, `Reference docs`, `News`, or `Other`.
   - `relevance`: Selected from a dropdown — `Critical`, `High`, `Normal`, or `Archive` — sets your reading priority.
   - `[[status]]`: Automatically set to `unread` on creation.
   - `antigravity-task`: Left blank (`~`) until Antigravity is assigned a summarization or tagging task.
   - The file is **automatically renamed** to `clip-YYYY-MM-DD-title-slug` at creation time.

2. **Core Sections**:
   - **Source Callout**: A `[!quote]` block showing the page title as a clickable link and the clip date — context at a glance.
   - **TL;DR**: A one-paragraph distillation of the content. Write this yourself or leave the `ANTIGRAVITY-HINT` comment for Antigravity to fetch and summarize the URL.
   - **Key Points**: A numbered list of the 3–5 most important takeaways from the page.
   - **Raw Clip**: A collapsible `<details>` block for pasting the full clipped Markdown from MarkDownload. Collapse or delete this section once you've extracted what you need.
   - **Related Notes**: A live Dataview query that surfaces other vault notes with the same `domain/` tag.
   - **Tags & Sort Checklist**: A processing checklist to work through before filing the note. When done, `status/unread` becomes `status/processed`.
   - **SORT-TARGET comment**: A hidden comment at the bottom that tells Antigravity which folder the processed note belongs in.

## How to Use the Web-Clip-Ingest Template

1. Install the [MarkDownload](https://github.com/deathau/markdownload) browser extension.
2. Configure MarkDownload to save clipped files directly to your vault's `Inbox/` folder.
3. When you find a page worth saving, click the MarkDownload icon and save to `Inbox/`.
4. Back in Obsidian, open the newly created file in `Inbox/`.

### Option 2: Manual Clipping

1. Create a new file in `Inbox/`.
2. Trigger Templater and select **[[Web-Clip-Ingest]]**.
3. Answer the [[[[prompts]]]] as above.
4. Paste or type the content directly into the **Raw Clip** section, or write the TL;DR and Key Points directly without pasting raw content.

## Processing Workflow

After a clip is ingested, work through it in this order:

1. **Read the page** — use the `url` field to reopen the original if needed.
2. **Write the TL;DR** — one paragraph maximum.
3. **Extract Key Points** — the 3–5 things worth remembering.
4. **Collapse or delete the Raw Clip** — once extracted, the raw content has no further value.
5. **Check Related Notes** — [[review]] the Dataview query; add `[[wikilinks]]` where relevant.
6. **Complete the checklist** — tick all boxes.
7. **[[Update]] [[status]]** — change `[[status]]: unread` → `[[status]]/processed` in frontmatter.
8. **Move the file** — follow the `SORT-TARGET` comment or move to the correct `domain/` folder manually.
