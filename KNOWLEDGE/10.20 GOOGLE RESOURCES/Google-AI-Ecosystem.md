Google's AI ecosystem spans consumer apps, enterprise workspace tools, developer platforms, and advanced cloud infrastructure.

Here is a comprehensive directory of Google's core AI-centric products, workspaces, and developer tools.

## Consumer & General Productivity Tools

- **Gemini**
    
    - **Description:** Google's primary multimodal AI assistant. It processes and generates text, images, code, and audio, serving as a general-purpose co-pilot across consumer apps, mobile devices, and the web.
        
    - **Link:** [https://gemini.google.com](https://gemini.google.com/)
        
- **NotebookLM**
    
    - **Description:** An AI-powered research assistant grounded strictly in user-uploaded documents (PDFs, Google Docs, text files, or YouTube links). It provides automatic summaries, citations, cross-document insights, and can generate conversational "Audio Overviews" (AI-generated podcasts) based on your sources.
        
    - **Link:** [https://notebooklm.google.com](https://notebooklm.google.com/)
        
- **Google AI Studio**
    
    - **Description:** A web-based prototyping environment for developers and power users to experiment with the Gemini model family. It allows for rapid prompt engineering, system instruction tuning, API key generation, and application testing with large context windows.
        
    - **Link:** [https://aistudio.google.com](https://aistudio.google.com/)
        

## Google Workspace AI [[Integration]]

- **Gemini for Google Workspace**
    
    - **Description:** The integrated AI layer native to the Google Workspace ecosystem. It provides inline writing help in Docs and Gmail, automatically generates spreadsheets and data templates in Sheets, builds visual slide decks in [[Slides]], and creates automated meeting summaries and notes in Google Meet.
        
    - **Link:** [https://workspace.google.com/solutions/ai](https://workspace.google.com/solutions/ai)
        
- **Google Vids**
    
    - **Description:** An AI-powered video creation and editing application built directly into Google Workspace. It assists users in generating video concepts, writing scripts, mixing templates, and producing professional-looking video content via natural language commands.
        
    - **Link:** [https://workspace.google.com/products/vids](https://workspace.google.com/products/vids)

## Coding, Engineering, & Agent Frameworks

- **Google Antigravity**
    
    - **Description:** An agent-first Integrated Development Environment (IDE) built to manage complex software engineering tasks. It coordinates multiple AI sub-[[agents]] simultaneously to handle code completion, full-stack refactoring, and automated debugging directly across a codebase.
        
    - **Link:** [https://cloud.google.com/use-cases/free-ai-tools](https://cloud.google.com/use-cases/free-ai-tools) _(Listed under Cloud AI developer tool previews)_
        
- **Firebase Studio** _(Integrating Project IDX)_
    
    - **Description:** A browser-based, full-stack AI development workspace tailored for building, testing, and deploying web and mobile applications. It integrates native AI coding assistants and deployment [[agents]] directly with Firebase and Cloud Run services.
        
    - **Link:** [https://firebase.google.com](https://firebase.google.com/)
        
- **Genkit**
    
    - **Description:** An open-source, modular framework designed for developers to build, run, and evaluate production-ready AI applications, Retrieval-Augmented Generation (RAG) pipelines, and autonomous [[agents]] across multiple model providers.
        
    - **Link:** [https://github.com/firebase/genkit](https://www.google.com/search?q=https://github.com/firebase/genkit)
        
- **Kaggle AI Models**
    
    - **Description:** A massive community repository and platform hosting open-source datasets, machine learning competitions, and a vast directory of open weights models—including Google's custom open-weight model family, **Gemma**.
        
    - **Link:** [https://www.kaggle.com/models](https://www.google.com/search?q=https%3A%2F%2Fwww.kaggle.com%2Fmodels)
