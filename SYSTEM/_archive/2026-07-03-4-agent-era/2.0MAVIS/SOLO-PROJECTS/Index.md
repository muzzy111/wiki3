# Solo Projects Index

> Mavis' solo project space. Documentation-only projects owned by Mavis end-to-end without dispatch.

## What Goes Here

- Documentation projects for the vault itself (style guides, conventions, onboarding docs).
- Karpathy wiki curation work in progress (when wiki work spans multiple sessions).
- Audit reports (long-form, beyond the weekly log).
- Cross-agent documentation harmonization (aligning docs across multiple folders).

## What Does Not Go Here

- User-facing deliverables — those live in `PROJECTS/`.
- Code with logic — that is OpenCode's domain.
- Web research — that is AGY's domain.
- Anything that requires user-facing communication — Hermes is the only channel.

## Current Projects

> None active. This folder will populate as Mavis takes on documentation work.

### Project Template

Each solo project follows this layout:

```
<project-slug>/
|-- README.md        (project brief, scope, acceptance criteria)
|-- PLAN.md          (steps, status)
|-- NOTES.md         (running notes)
`-- DELIVERABLE.md   (final artifact or pointer to it)
```

Mavis updates `Index.md` (this file) with a one-line summary of each project.
