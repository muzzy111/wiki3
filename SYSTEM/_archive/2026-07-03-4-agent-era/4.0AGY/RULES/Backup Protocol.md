# Backup Protocol

> The backup contract AGY follows for the Google Drive mirror of the vault.

## Scope

This protocol governs the **continuous, one-way sync** of the local vault to Google Drive. The local vault is the source of truth. The remote is the safety net.

## Sync Direction

**Local -> Drive. Always.** AGY never pulls from Drive into the local vault. AGY never overwrites local with remote.

## Sync Trigger

AGY runs the sync on a schedule:

- **Default interval:** 15 minutes.
- **Configurable via env var:** `AGY_SYNC_INTERVAL_MINUTES`.
- **Manual trigger:** AGY may run an immediate sync on user request via Hermes.
- **Forced full sync:** On initial setup, or after a detected mismatch.

## Sync Process

1. **Snapshot local.** AGY enumerates the local vault, excluding:
   - `.obsidian/workspace.json` (ephemeral, regenerated locally).
   - `.smart-env/event_logs/event_logs.ajson` (ephemeral).
   - Any path in the exclude list (configured via env var or in `4.0AGY/RULES/Backup Protocol.md`).

2. **Compare with remote.** AGY lists the remote mirror, excluding the same paths. Compares by file path and modification time.

3. **Compute deltas.** For each file:
   - Local exists, remote missing -> upload.
   - Local exists, remote exists, local newer -> upload (versioned).
   - Local exists, remote exists, same -> skip.
   - Local missing, remote exists -> flag for review (do not auto-delete remote).

4. **Transfer.** Upload changes via the Google Drive API. Use exponential backoff on transient failures.

5. **Verify.** After transfer, re-snapshot both sides and confirm file counts match within tolerance (modulo legitimate remote-only items).

6. **Log.** Append a row to `MEMORY/Backup Log.md`.

## Versioning

The remote retains the last N versions of each file (default 30). Older versions are pruned. Versions are timestamped.

## Failure Handling

### Transient errors

- Network blip, rate limit, temporary auth issue -> retry with backoff up to 5 times within an hour.

### Persistent errors

- After max retries, AGY:
  1. Writes a critical entry to `Backup Log.md`.
  2. Notifies Hermes via the inbox.
  3. Suggests remediation (check auth, check quota, check network).

### Auth failure

- Drive token expired or revoked. AGY stops sync. Writes an entry to `SYSTEM/STYTEM RECORD/` requesting user intervention. Notifies Hermes. The user must re-authorize.

### Quota exceeded

- Drive storage full. AGY stops sync. Notifies Hermes. Suggests cleanup or quota upgrade.

### Conflict

- Local modified, remote modified (somehow, since sync is one-way). Local wins. Remote change logged as conflict and overwritten on next sync.

## Verification

AGY performs a checksum-based verification:

- Daily at 03:00 local time (configurable).
- Compares MD5 (or stronger) hashes of local and remote files.
- Reports any mismatches to the log.

If mismatches are detected and the local is the desired state, AGY forces a re-upload of mismatched files.

## Restore

Restore is rare and explicit:

- **Target directory:** A fresh directory, never the live vault.
- **Point-in-time:** User specifies a timestamp; AGY restores from the versioned remote closest to that timestamp.
- **User confirmation required:** AGY confirms before any restore operation.

## Excluded Paths

Default exclusions:

- `.obsidian/workspace.json`
- `.obsidian/backlink.json` (regenerated by Obsidian)
- `.smart-env/event_logs/event_logs.ajson`
- Any `*.tmp` file
- Any file matching the configured exclude patterns

AGY never excludes files silently. Every exclusion is documented in this file or in env config.

## Health Reporting

AGY reports backup health:

- **In Backup Log:** Every run.
- **In AGY Memory:** Weekly trend (Mavis writes).
- **To Hermes:** On failure, immediately. On success, never (unless `/silent` is not set and a sync took unusually long).

## Disaster Recovery

If the local vault is lost:

1. User notifies Hermes via chat or command pad.
2. Hermes dispatches to AGY: restore from Drive.
3. AGY confirms the latest successful sync timestamp.
4. User confirms the restore target directory.
5. AGY restores.
6. AGY verifies the restore.
7. Mavis reviews the restored vault and reports on integrity.
