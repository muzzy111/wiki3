# Researcher Skill Set

> Preview of the skills the Researcher role owns.

## Starter Skills

- **Web Research**
  - Purpose: Multi-source web research via agy or the fetch MCP server. Sourcing discipline (URLs, dates).
  - migrates_from: 4.0AGY/SKILLS/Web Research.md

- **Sourcing Discipline**
  - Purpose: Cite every claim. Primary source > secondary. Wayback fallback for dead links.
  - migrates_from: 4.0AGY/SKILLS/Web Research.md (sourcing rules section)

- **Research Brief Anatomy**
  - Purpose: Author `Question -> Scope -> Sources -> Findings -> Caveats -> Suggested Follow-ups` briefs.
  - migrates_from: 4.0AGY/SKILLS/Web Research.md (brief format section)

- **Karpathy Wiki Pipeline**
  - Purpose: Convert raw session journals into atomic wiki notes following the 3-folder flow.
  - migrates_from: 2.0MAVIS/SKILLS/Karpathy Wiki Curation.md (research portion)

- **Research Brief Protocol**
  - Purpose: How the Researcher role accepts briefs and writes completions.
  - migrates_from: 4.0AGY/CHAT/Research Brief Protocol.md
