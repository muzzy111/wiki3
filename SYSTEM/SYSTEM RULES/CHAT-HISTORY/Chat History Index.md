# System Rules — Chat History

> Mirror of the `CHAT-HISTORY/` folder shape inside `SYSTEM/SYSTEM RULES/`. Holds system-rule-specific chat history.

## Why This Mirror Exists

The six-subfolder shape (`CHAT-HISTORY`, `MEMORY`, `PROMPTS`, `RULES`, `SKILLS`, `SOLO-PROJECTS`) is intentionally mirrored across all agent-shaped folders (per `SYSTEM/SYSTEM GRAPH/Graph`). This folder is the system-rule-specific instance.

## What Goes Here

- Chat history related to system rule evolution.
- Decision conversations captured when a rule was created or changed.
