# System Rules — Solo Projects

> Solo projects related to system rules. Owned by Hermes (rule proposals) or Mavis (rule audits).

## Why This Mirror Exists

The six-subfolder shape is mirrored across agent-shaped folders. This folder holds solo projects that started as system-rule work.

## What Goes Here

- A rule-proposal project (drafting a new rule end-to-end).
- A rule-audit project (auditing compliance with a specific rule).
- A rule-retirement project (deprecating an obsolete rule).
