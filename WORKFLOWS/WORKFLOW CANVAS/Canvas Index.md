# Workflow Canvas

> Visual designs of workflows. Canvas files (.canvas) that show how a workflow flows step by step.

## Purpose

Some workflows are best understood visually. The Workflow Canvas folder holds:

- **Visual workflow diagrams.** Step-by-step flow with decision points.
- **Process maps.** How multiple workflows interact.
- **Reference diagrams.** For onboarding or audit.

## Subfolder Layout

The Workflow Canvas folder mirrors the standard six-subfolder shape (per `SYSTEM/SYSTEM GRAPH/Graph`):

```

|

|-- DEVELOPED/                developed canvas entries
|-- MEMORY/                   canvas-related memory
|-- RAW/                      raw canvas drafts
|-- RULES/                    canvas-related rules
`-- SOLO-PROJECTS/            canvas-related solo work
```
