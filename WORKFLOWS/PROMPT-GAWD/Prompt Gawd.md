# PROMPT-GAWD — Prompt Engineering and Testing

> The team's prompt engineering workspace. Drafts, tests, comparisons, and a library of proven prompts.

## Purpose

PROMPT-GAWD is for:

- **Prompt drafting.** Authoring new system prompts for agents, skills, or workflows.
- **Prompt testing.** Running prompts against reference inputs to verify output.
- **Prompt comparison.** Side-by-side comparison of prompt variants.
- **Prompt library.** A canonical store of proven prompts with version history.

## Status

**Draft.** No prompts here yet. Initial intake will come from `<agent>/PROMPTS/*.md` files.

## What Lives Here

- **Prompt drafts.** Under review.
- **Prompt tests.** Reference inputs and observed outputs.
- **Prompt comparisons.** When choosing between variants.
- **Prompt library.** Proven prompts with version history and changelog.

## When To Promote a Prompt

A prompt graduates from a draft to the library when:

- It has been tested against at least 5 reference inputs.
- Output is consistent and meets the spec.
- Mavis has reviewed and approved.
- Version is tagged.
