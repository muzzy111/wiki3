## Maintenance rules

1. **One idea per file** — if two prompts overlap, merge or delete the weaker one  
2. **YAML frontmatter required** — `name`, `description`, `type`, `tags`, `status`  
3. **No web-scrape chrome** — keep portable prompt text, not navigation dumps  
4. **Prefer technique notes** over five near-duplicate blog clips  

## Types

| `type` | Meaning |
|---|---|
| `agent-prompt` | Role / persona agent |
| `system-prompt` | Full system prompt from a product or operator doctrine |
| `model-prompt` | Model-specific notes / tuning |
| `specialty-prompt` | Task-scoped template with inputs |
| `technique-prompt` | Consolidated design playbook |
| `dashboard` | Index / overview |
