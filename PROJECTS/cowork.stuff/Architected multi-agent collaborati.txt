powershellGet-ChildItem -Path "C:\Users\Admin\Documents\GitHub" -Recurse -Filter ".git" -Force -Directory | Select-Object FullName
That will tell you the real root of your repo.

Step 2 — Skip git entirely, use a file tree instead
Since your repo root isn't a standard single git repo, just use PowerShell's file crawler with noise folders excluded. This works regardless of git:
powershell$root = "C:\Users\Admin\Documents\GitHub"
$out = "$root\Chat\repo-manifest.md"
$exclude = @('.git','node_modules','__pycache__','.venv','dist','build','.next','Hermes','OpenCode','Antigravity','Chat','Build','Source')

"# Repo Manifest`n`nGenerated: $(Get-Date)`n``````" | Set-Content $out

Get-ChildItem -Path $root -Recurse -File -Force | Where-Object {
    $parts = $_.FullName.Replace($root,"").Split('\')
    ($parts | Where-Object { $exclude -contains $_ }).Count -eq 0
} | ForEach-Object {
    $_.FullName.Replace($root + "\","")
} | Add-Content $out

"``````" | Add-Content $out
