## How to use this folder

- Each file is named `NNN-short-slug.md` so they sort in the order i'd work them.
- Read the **what** (one line), then the **how** (numbered steps with screenshots/URLs), then the **why** (so you can decide if it's worth it).
- When done, flip the **[[status]]** at the top of the file from `open` → `done` and add a one-line note in the **## Done** section.
- Tasks i create going forward land here, not in chat. Chat is for the work; this folder is for your queue.
