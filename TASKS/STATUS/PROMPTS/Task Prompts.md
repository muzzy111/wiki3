# Task Prompts

> Reusable prompt fragments for common task types. Hermes authors; Mavis reviews.

## What Lives Here

- Fragments for common dispatch briefs (e.g., "code brief template", "research brief template").
- Fragments for common reviews (e.g., "code review checklist prompt").
- Fragments for common replies (e.g., "task complete reply template").

## File Naming

`<task-type> — <purpose>.md`. Examples:

- `Code — Brief Template.md`
- `Research — Brief Template.md`
- `Review — Code.md`
- `Reply — Task Done.md`
