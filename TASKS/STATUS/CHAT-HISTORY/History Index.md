# Task Chat History

> Per-task chat history snapshots. When a task's chat is long enough to warrant a summary, Hermes writes it here.

## What Lives Here

- Per-task chat digests.
- Decision points captured during a task.
- Notable conversations referenced from a task card.

## Cadence

Hermes writes a digest when:

- A task involves more than 10 chat turns.
- The task generates decisions worth recording.
- The user asks for a record.

## File Naming

`<task-id> — Chat Digest.md`.
