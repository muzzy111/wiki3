# Task-Initiated Solo Projects

> Solo projects that started as tasks. When a task grows beyond a single deliverable, it graduates to a solo project here.

## What Lives Here

Each entry is a record of:

- The originating task-id.
- The reason for graduation.
- The new project location.
- The handoff notes.

## When a Task Graduates

A task graduates to a solo project when:

- The work has expanded beyond what the original task card can track.
- The work is expected to span multiple sessions.
- The user wants visibility into the work as a project, not just a task.

## File Naming

`<task-id> — Graduation.md`.
