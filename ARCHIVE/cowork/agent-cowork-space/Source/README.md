# Source — inputs and reference material

Drop reference repos, ingested data, and other inputs here. Read-only
for agents; only humans (and the orchestrator with explicit approval)
add to this folder.

```
Source/
├── README.md
└── <repo-or-dataset-name>/
```

Convention: when ingesting an external repo, also create a
`Source/<repo>/INGEST.md` with: source URL, license, ingest date,
size, and any curation notes.

Empty at template bootstrap.
