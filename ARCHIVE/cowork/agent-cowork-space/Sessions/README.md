# Sessions — chronological session logs

One file per working session, named `Day-N-<slug>.md` or
`<YYYY-MM-DD>-<slug>.md`. Modeled on VaultOS-v.02's day journals
(`AntiGravity Day 1.md`, etc.).

Each entry includes:

- Date and session number.
- Participants (agents + humans).
- Goal of the session.
- Timeline of events.
- Decisions made.
- Work completed (links to Build/, Outbox/).
- Blockers / open questions.
- Plan for next session.

Empty at template bootstrap.
