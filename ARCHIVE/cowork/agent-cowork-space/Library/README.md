# Library — reusable assets

Skills, prompt snippets, schemas, and other reusable assets that
outlive a single project.

```
Library/
├── README.md
├── skills/                ← reusable skills (SKILL.md + frontmatter)
├── prompts/               ← reusable prompt snippets
├── schemas/               ← JSON schemas for validation
└── fixtures/              ← test data, sample inputs
```

Empty at template bootstrap.
