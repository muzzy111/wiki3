# Outbox

Finalized deliverables awaiting human review or external handoff.
When a project is complete, the project lead copies its key artifacts
here.

```
Outbox/
├── README.md
└── <project-name>/
    ├── <deliverable-1>.md
    ├── <deliverable-2>.md
    └── MANIFEST.md   ← what's here, when produced, by whom
```

Empty at template bootstrap.
