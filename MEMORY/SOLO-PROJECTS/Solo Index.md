# Shared Solo Projects

> Documentation for cross-agent solo work that does not belong to any one agent's folder.

## What Lives Here

When a project spans multiple agents and is small enough not to warrant a `PROJECTS/` entry, it lives here. Examples:

- A documentation cross-linking effort (Mavis-led, with help from AGY).
- A vault-wide refactor (OpenCode-led, with Mavis documentation).
- A system-level cleanup (Hermes-led, with everyone).

## Project Layout

Each project follows the standard layout:

```
<project-slug>/
|-- README.md        project brief, scope, acceptance criteria
|-- PLAN.md          steps, status
|-- NOTES.md         running notes
`-- DELIVERABLE.md   final artifact or pointer to it
```

## Curation

Projects are added by any agent that initiates the work. Mavis ensures consistency.
