# Shared Memory Notes

> Notes that are useful across multiple agents. Not atomic enough for the wiki. Mavis curates.

## What Lives Here

This is the catch-all for cross-agent notes that don't fit the wiki's atomicity rule. Examples:

- Operational runbooks (multi-step procedures).
- Reference material that needs context to be useful.
- Conventions and standards that span multiple agents.
- Glossaries of domain terms the team uses.

## Curation

Mavis writes. Other agents read.

For each note, Mavis ensures:

- Frontmatter is complete.
- Wikilinks resolve.
- Voice matches the vault voice.
- The note has a clear purpose stated at the top.

## File Naming

`<topic> — <short description>.md`. Examples:

- `Backup Recovery Runbook.md`
- `Citation Style Guide.md`
- `Glossary — ML Terms.md`
